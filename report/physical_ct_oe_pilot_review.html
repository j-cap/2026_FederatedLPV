Analytical structure changes the conclusion

Audit of pilot fleets 1301–1303 • 90 vehicles • 249 original vehicle–speed records • no new fitting or control runs

Main finding

The four-parameter local model reduces mean unobserved-speed matrix error to 0.386%, versus 2.266% for Federated and 4.500% for Global. This supports Markus’s concern that much of the apparent need for sharing in this vehicle benchmark comes from the flexible scheduling representation. It does not establish that federation is generally unnecessary.

2. Why this matters for the paper

The earlier rank-deficiency statement is valid for the seven-function, 42-coefficient representation. It does not show that a vehicle lacks enough information to identify an appropriately structured model. The current fit links all matrix entries and speeds through Cf/m, Cr/m, m/Iz and μ, exploiting known geometry and the correct tire-law structure.

The comparison changes both parameterization and joint across-speed estimation. It is not a clean attribution to fewer parameters alone. Nonetheless, it is the relevant practical baseline: the vehicle-focused paper must explain why such available structure would be insufficient before presenting federation as necessary for speed coverage.

The identification solver receives only noisy state measurements, known applied steering, observed speeds and fixed model settings. It uses neither recipient truth, family labels, validation trajectories nor the old fitted matrix targets. True parameters are used afterward to assess parameter recovery.

The strongest exception, seed 1302 / handling_04, estimates μ=1.5 at the upper bound although the simulator uses μ=0.9. Its other parameter errors remain below 0.5%. Do not call this reliable physical friction recovery simply because the optimizer converged.

Analytically, s(v)=1−κ²v⁴/(μ²g²), so ∂s/∂log μ=2κ²v⁴/(μ²g²). At fixed curvature this part of friction sensitivity grows as v⁴. This explains why low-speed observations can be structurally sufficient across speeds yet weakly informative about friction in practice. It is a possible motivation for future sharing, not evidence that sharing is already needed on average here.

5. Validation and optimization checks

Saved independent chirp-validation scores favor structured local CT in 239 / 249 observed-speed cases. With equal-vehicle/equal-fleet averaging, normalized affine rollout error is 0.001517 versus 0.002178 for the original local affine OE fits. This is an observed-speed comparison, not evidence about unseen nonlinear trajectories.

All 360 of 360 starts converged. The maximum within-vehicle spread of training losses is 5.04e-14; the maximum relative parameter spread is 1.12e-05. The result is not explained by one unusually favorable start.

Audit checks: original source and checkpoint hashes; all 249 training measurement/input hash pairs; training-loss selection; all saved structured grid matrices; all 4950 method–vehicle–speed metric rows; historical baseline errors; aggregate CSV reproduction. Validation scores were checked against saved records and original baseline values, but could not be replayed here because the original byte-identical raw trajectories are not available.

6. Recommended decision before further manuscript work

  1. Use the structured model as the new local baseline. Pause claims that incomplete local speed coverage alone establishes a need for federation in this plant.
  2. Run the already prepared pilot closed-loop comparison next. Keep weights, maneuvers and all bounds unchanged; better identification does not automatically imply better tracking.
  3. If the control result is consistent, apply the unchanged diagnostic to the ten existing evaluation fleets. These data have already been inspected and should be described as an extension, not fresh confirmation.
  4. Discuss the paper’s scope with Markus. A future federated structured model would need a demonstrated practical local limitation, such as weak excitation or unavailable sideslip. Neither changing heterogeneity to favor grouping nor widening the scope without new evidence would address the current criticism.

The report does not authorize or execute these next experiments. The manuscript is unchanged. No yaw-only identification or new state observer has been tested.
