Does loading create a meaningful local-adaptation window?

Scope and comparison

Nine reused pilot vehicles, 10/20/30% added mass, centered at the existing CG with known 1 m payload radius of gyration. Geometry, cornering stiffness and friction remain fixed in this controlled simulation. Loading occurs before straight-running initialization, not mid-corner. This is a screen for an adaptation opportunity, not a fleet-learning experiment or a production validation.

Previous uses the same saved pre-change yaw-only CT model. KnownChange applies the true loading fraction to that same identified model; it does not replace the whole model with plant truth and is not a guaranteed performance bound. Local estimates one loading fraction in [0,0.5] using nonlinear yaw-only OE. All use identical controller weights, observer covariances, limits, test references and paired test noise.

One 40-second acquisition trajectory per loading case uses the previous controller/observer at 20 m/s, four smooth left–right curves, nominal lateral demand 1.5 m/s², and no steering dither. Only measured yaw and applied steering enter fitting, at 4/8/16/32/40-second prefixes. Known zero initial state; no affine offsets, latent sideslip pseudo-measurements, future-sample normalization or model updates during acquisition. Noise SD is 0.03°/s. The curves are prescribed and road-inspired, not measured ordinary driving.

135 scalar fits and 567 held-out 12-second control runs at 13/21/29 m/s. Baselines are simulated once per case/speed, then reused in prefix comparisons. Evaluation resets to straight running: these are fixed-model tests after each prefix, not online adaptation rollouts. Pre-change models retain their original full-state-feedback acquisition history.
