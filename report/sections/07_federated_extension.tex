\section{Federated extension after the oracle gate}
Only a positive oracle result justifies replacing its assumptions one at a time.
Each client will then observe a short, noisy, partial speed envelope and estimate
LPV coefficients and uncertainty locally. The server must recover useful shared
and family-specific structure without raw trajectory exchange. The planned
sequence adds partial scheduling coverage, observation noise and finite data,
uncertainty-aware aggregation, learned family assignment, partial participation,
and communication limits. Changing payload, online reassignment, robust LPV
synthesis, and high-fidelity vehicle validation remain later extensions.
