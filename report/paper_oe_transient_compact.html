Publication layout: three speed columns, shared reference row, then tracking errors for both fixed recipients. All six error axes are identical. No smoothing, time-window selection, normalization or new simulation.

Figure preview. Fixed-speed yaw-rate tracking at three speeds unobserved in local identification. Top: reference. Middle and bottom: e_r = r − r_ref for the fixed heavy and handling recipients. The nominal lateral demand is identical across speeds.

The full response can be read as r = r_ref + e_r. Separate error axes reveal small differences without hiding the reference scale. The trials have zero longitudinal acceleration. Steering traces remain in the full benchmark report because they add little visual separation here.

Recipients: fleet 1319, heavy_05 and handling_07. They were fixed before this benchmark; no reselection was made. The handling example is not evidence of a uniform family-wide benefit. Retain the family-level qualification in the manuscript.

ISO-7401-inspired yaw-reference tracking adaptation, not an ISO-compliant steering-input test. Noise-free state feedback and the existing nonlinear tanh-tire plant are used.

LaTeX integration

The nine data PDFs and shared legend are separate files. Panel letters and speed labels come from LaTeX. The figure uses 2.30-inch panels at native size (8 pt axis labels, 7 pt ticks), with a total two-column width of approximately 7.16 inches.

The manuscript includes \input{figures/oe_transient_figure} to paper/main.tex. The file uses the manuscript's existing graphicspath and subfig package. Its caption revision color is controlled by the manuscript.

Regenerate with python paper\prepare_oe_transient_figure.py --generate, then verify with python paper\prepare_oe_transient_figure.py --check. Add --compile-preview to generate when a LaTeX installation is available.

Input checks use the committed trace/metric/checkpoint hashes and recompute displayed RMSE from the trace CSV. They do not regenerate the floating-point sine waveform, so plotting is portable without weakening the original simulation checks.
