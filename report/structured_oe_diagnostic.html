What this experiment answers

The previous pilot produced accurate local matrices with exact simulated states, but large errors with noisy measured states—even when steering was known. This diagnostic keeps the physical trajectories, noisy states, speed coverage and applied steering fixed and changes how the local dynamics are fitted.

KnownOLS is the frozen one-step fit with quiet-segment centering. AffineOLS adds a fitted constant term. StructuredOE simulates the full training segment and fits the same affine A/B dynamics together with an initial state. Physical coordinates are fixed by C = I. The clean OLS reference is for diagnosis only.

The question is whether these driving maneuvers support local identification with measurement noise. This experiment does not yet test federated sharing, full-envelope interpolation, changing-speed behavior, or controller performance.

The low-speed failure is removed in this pilot

At 10 m/s the gentle profile changes from 57.30% median matrix error under known-input OLS to 1.00% under OE. Its worst cell is 6.06%, below the unchanged 10% threshold. The original low-speed tail is therefore not an unavoidable consequence of these trajectories.

The canonical metric evaluates A/B using the common validation center, preserving the original gates. The full-affine metric uses each model’s training-derived offset, without fitting a new validation offset. Both evaluate independent chirp maneuvers and restart one-second windows at the exact simulator state. Values are dimensionless normalized RMSE, not percentages or an observer performance measure.

The stronger excitation gives slightly better matrix-error tails but higher OE validation prediction errors. This pattern is consistent with increased local-linear approximation error at larger amplitudes; this comparison does not isolate that mechanism. Gentle already meets the required matrix accuracy and has the lowest OE prediction-error tail.

Numerical audit: keep the multiple starts

Every selected fit converged, has a full-rank 10-parameter Jacobian, and has spectral radius between 0.8629 and 0.9761. No stability constraint was imposed. These checks support numerical usability but do not prove global optimality or general identifiability.

Of 2241 starts, 42 reached the evaluation limit. Five additional starts converged to poor solutions with large matrix errors. All five had higher training loss and were rejected by the predeclared selection rule. Every case has at least two starts within 10⁻⁶ relative training objective of the best solution; their largest pairwise matrix difference is only 0.000316% of the reference matrix norm.

Do not replace the three-start procedure with one arbitrary initialization. “Solver converged” alone was insufficient for several starts. The saved lowest-training-loss selection is part of the estimator protocol.

Recommended next step

Freeze gentle excitation with structured OE as the candidate for independent confirmation. It is the smallest tested excitation and passes all original criteria. Keep the existing state-noise levels, known applied steering, physical coordinates, three starts, offset/initial-state handling and acceptance thresholds fixed.

  1. Define the revised confirmation protocol using the untouched confirmation seeds. Preserve the original rejected OLS selection as historical evidence.
  2. Confirm local matrix recovery first. Then pass the resulting local A/B estimates into the federated speed-basis regression and rerun the relevant comparisons with the same estimator for every method.
  3. Check how the changed local estimator affects regression weights, local-prior equivalence statements and operating-point handling before manuscript integration.

The present analysis does not unlock the old confirmation runner or change the historical pilot selection. It does not justify a claim about ordinary driving, production sensing, noisy speed measurements or real-vehicle validation. Both sideslip and yaw rate are measured here, and the estimator uses the declared simulation measurement variances.

Provenance and reproducibility

Nine checkpoint hashes and nested source locks verified. All 2241 saved matrix errors were independently recomputed from A/B and the frozen references. The known-steering baseline, common validation centers, pass flags and training-loss selection were checked. The original summary CSVs, analysis JSON and generic report were regenerated without differences before this interpreted report was created.

Raw trajectories are ignored by git and were unavailable in this workspace. This audit did not rerun fits or validation rollouts; it verifies saved numerical outputs and their provenance. No new scientific simulation was run.
