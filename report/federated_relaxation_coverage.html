Can peers improve prediction outside a vehicle's observed speed?

Exploratory three-fleet pilot. Nine vehicles per fleet, one 12 s record per vehicle, identical four-state nonlinear model class. No control experiment or automatic scientific pass.

Methods and access to data

LocalOE fits each vehicle independently. NominalPrior applies the same fixed shrinkage to a common engineering nominal value. Global learns one common parameter vector from federated Gauss–Newton messages. FedPersonal uses one learned center and personalized parameters. FedGroups uses three learned centers and personalized parameters. Exact uses the generating parameters only as an evaluation reference.

All local fits use the same three predefined starts, independent of previous identified models and vehicle truth. Only the five dynamic/relaxation parameters enter the sharing penalty; friction remains locally free. The simulated population has common generating relaxation lengths, which is favorable for transfer and must be stated when interpreting results.

Interpretation

A useful outcome is lower peer-speed error without unacceptable loss at the observed speed, consistent across fleets and beyond the fixed nominal-prior baseline. If Global is already competitive, grouping may be unnecessary. If local models already generalize well, these data do not demonstrate a need for sharing. Poor local estimates alone do not show that peers supply the missing information.

Friction errors, active bounds, optimizer status and local sensitivity are saved in checkpoints. Parameters and data are never repaired using evaluation trajectories. Test frequencies/phases and sensor-noise streams are separate from training. The four-state controller issue remains outside this experiment.
