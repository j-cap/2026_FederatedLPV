Can yaw measurements distinguish tire-force relaxation?

A focused information diagnostic before identification/control comparisons. Protocol version 1.

Question and limits

We extend the existing tanh bicycle model by two axle-force states. First determine whether those states are observable with known parameters and whether yaw measurements distinguish the two relaxation lengths. No Pacejka change, vehicle loading change, controller redesign, fleet prior or manuscript rewrite is included.

Full numerical state-observability rank is not structural parameter identifiability. Good yaw prediction is not proof of unique force reconstruction. This screen produces evidence about local information and conditional objective shape; it does not provide a global identifiability theorem or an automatic pass decision.

Model and parameterization

At fixed positive longitudinal speed v, use x = [β, r, qf, qr]T, where qj = Fyj/m. Physical ratios are p1 = Cf/m, p2 = Cr/m, p3 = m/Iz. The friction coefficient is μ, and the positive front/rear relaxation lengths are σf, σr. Geometry lf, lr is known; L = lf + lr.

αf = δ − β − lfr/v,   αr = −β + lrr/v
qfss = (μg lr/L) tanh[p1αf/(μg lr/L)]
qrss = (μg lf/L) tanh[p2αr/(μg lf/L)]
dβ/dt = (qf + qr)/v − r
dr/dt = p3(lfqf − lrqr)
dqj/dt = (v/σj)(qjss − qj),   j ∈ {f,r}
yk = r(tk) + εk,   εk ∼ N(0,sr2)

These are small-angle body/slip kinematics with nonlinear tanh forces and static axle loads. The force states represent a first-order approximation, not a complete tire model. Using normalized forces avoids introducing an unidentifiable absolute mass/force scale. The simulator's true states are used only for diagnostic checks and clean yaw targets.

Observability and parameter information

Known-parameter state observability: linearize at straight running, discretize exactly under ZOH, and stack C Adk for 2 s. Scale states by [0.5° β, 2°/s r, 2 m/s² qf, 2 m/s² qr] and whiten yaw by its noise SD. Report singular values, numerical rank, and condition number.

Negative check: for equal relaxation times τ and physical-force coordinates, det(O) = L(lfCf−lrCr)²/(Iz³mτ²v). The normalized implementation has the same rank. A balanced case lfCf = lrCr must have rank 2. A small imbalance sweep shows how the singular values change. Zero steering with zero initial state must give zero parameter information even when known-parameter state observability is full.

Nonlinear trajectory sensitivities: compute Skj = (1/sr) ∂r(tk)/∂log θj by complex step through the nonlinear RK4 predictor. The six θ entries are p1,p2,p3,μ,σf,σr. Initial-state derivatives use the declared state scales. Finite differences independently verify the derivatives in tests.

For the relaxation columns Sσ and nuisance columns N, use Seffective = (I−NN†)Sσ. Compare four cases: exact CT/initial values; unknown initial state; unknown CT ratios and μ; both unknown. This is an unregularized local projection, not a nonlinear refit. The rank threshold for the projected relaxation matrix is referenced to the unprojected relaxation matrix so numerical cancellation cannot become apparent information. Relative SVD threshold 10−9 is primary; 10−8 and 10−10 alternatives are saved.

Conditional grid profiles: plot weighted SSE and its grid minimum over the other relaxation length. True CT is an optimistic diagnostic; Previous CT exposes absorption of existing model error. These surfaces hold the CT parameters and initial state fixed. They are not full nuisance-profile likelihoods, exact MLEs, or confidence intervals. Reference: Raue et al. (2009) for the distinction between structural/practical identifiability and fully optimized profile likelihoods.

Decision after inspection

Proceed to an estimator and the small controlled plant comparison only if the information is adequate under the stated sensing assumptions, or after explicitly resolving a weak parameter direction. Review operating checks, nuisance sensitivity, objective valleys, boundary minima and shifts caused by baseline-model error together. Neither the number of states nor a full-rank matrix is enough. A subsequent comparison must give the local baseline the same augmented physical model as the shared method.

If two lengths cannot be distinguished, options include a justified reduced parameterization, additional measured lateral acceleration, or a different justified excitation. Sharing identical uninformative records cannot resolve a structural ambiguity.
