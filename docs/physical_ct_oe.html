Does analytical vehicle structure remove the need for sharing?

Prospective diagnostic prompted by Markus Gurtner’s November 24 review. The manuscript and all historical results stay unchanged. This is a reanalysis of existing data, not fresh independent confirmation.

Question and controlled comparison

The existing model has 42 scheduling coefficients per group. The proposed local model uses four dynamic parameters per vehicle, jointly fitted over its existing two or three observed speeds. Compare it with the frozen Restricted Local, Smooth Local, Global, and Federated models. This tests whether the claimed local information deficit depends on a needlessly flexible representation.

Analytical model

p₁ = Cf/m,   p₂ = Cr/m,   p₃ = m/Iz,   μ unknown
k = lrp₂ − lfp₁,   q = lf²p₁ + lr²p₂
s(v) = 1 − (κv²/(μg))²
A₁₁ = −s(p₁+p₂)/v,   A₁₂ = −1 + sk/v²
A₂₁ = sp₃k,   A₂₂ = −sp₃q/v
B₁ = sp₁/v,   B₂ = slfp₁p₃

Known geometry is lf=1.2 m, lr=1.6 m; κ=0.005 m⁻¹. For tanh tires the slope is C[1−(F/(μFz))²]. Steady force/moment balance and static axle loads give F/(μFz)=κv²/(μg) on both axles. This is the analytical local Jacobian at steady cornering, not an exact model of finite-amplitude nonlinear trajectories.

The common simulator friction is 0.9, used only for evaluation of parameter recovery. It is not fixed in fitting. Bounds are p₁,p₂∈[10,150], p₃∈[0.2,1.2], μ∈[0.5,1.5]. The friction lower bound permits the specified equilibrium over the target interval; the critical value at 30 m/s is about 0.459. Bounds are assumptions, and bound hits are reported. No stability clipping or fallback is applied.

At one speed only sp₁, sp₂ and p₃ determine the matrices. Unknown friction cannot generally be separated from stiffness ratios there. Multiple speeds can remove this structural ambiguity, but practical sensitivity may remain weak. The tests explicitly verify rank three at one speed and rank four in a suitable two-speed synthetic example.

Estimator and efficiency

Exact zero-order-hold discretization uses Ts=0.01 s. Residuals are simulated full-state deviations divided by the original measurement-noise standard deviations (0.01° and 0.03°/s). No numerical differentiation of measured states is used.

The nonlinear optimizer sees only four log parameters. At each trial, four free nuisance quantities per trajectory (two discrete affine offsets and two initial states) are solved by weighted linear least squares. This variable projection is equivalent to jointly minimizing over those nuisance quantities. Centering is numerical only and imposes no equilibrium prior. Matrix-exponential Fréchet derivatives and the full projected-residual Jacobian accelerate fitting.

Four deterministic starts are fixed in the JSON protocol. The first is the common nominal parameter vector; the others vary stiffness ratios, inertia ratio and friction. Starts do not use existing fitted models, recipient parameters, family labels or evaluation accuracy. Selection is the lowest training loss among converged starts. Every attempt, termination status, bound flag, sensitivity and fitted nuisance quantity is saved.

Workers operate on separate fleets, each with one BLAS thread. Three workers use all pilot fleets; up to ten can be used later. Avoid concurrent restore/run commands for the same cohort. What to inspect

  1. Convergence and bounds first. A failed client leaves the whole fleet mean unavailable for that method. There are no survivor-only primary means.
  2. Historical unseen-speed relative matrix error, using exactly the previous reference matrices and equal-vehicle/equal-fleet aggregation.
  3. Relative A and B errors; identity-free increment error normalized by [A−I,B]; absolute matched discrete-pole RMS; separate sideslip and yaw pulse-response errors. The increment metric still depends on coordinates and is not claimed as a universal control metric.
  4. Observed-speed chirp validation using training-derived affine offsets, original state scales and true initialization per one-second window. This is an identification diagnostic, not an observer test.
  5. Fitted physical parameters, truth-relative errors (evaluation only), projected sensitivity singular values, weakest log-parameter direction, column correlations and single-speed versus joint information.
  6. Optional closed-loop tracking, constraints and failures under the existing benchmark. Noise-free state feedback remains unchanged; no claim about production sideslip sensing.

Pulse comparisons are local linear model responses to 0.3° steering for 0.2 s over a 2.01-s horizon. They do not require a new nonlinear calibration trajectory. Pole errors match the two eigenvalues over both permutations. No continuous-time matrix logarithm is used to manufacture physical parameters for the unstructured baselines.

Success would challenge the necessity of our flexible representation for this plant. Failure would require diagnosing finite-amplitude mismatch, weak information, parameter bounds or numerical issues before concluding that federation is needed. Neither outcome is filtered from the report.
