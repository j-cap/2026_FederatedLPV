Fixed-speed structured output-error diagnostic

Frozen development protocol. Implemented for local execution; no pilot OE results have been produced during implementation.

Question and scope

Can a local estimator designed for noisy state measurements recover accurate physical A/B matrices from the existing continuous calibration trajectories? Use all 747 existing client–speed cells: seeds 1301–1303, gentle/standard/strong profiles, 83 cells per seed and profile. No new physical trajectories, changed excitation, sensor realizations, estimator tuning on validation, federation, or controller experiment.

The input is the exact applied steering after limiting. Sideslip and yaw-rate measurements retain their existing noise. Both states are available for calibration; this does not establish feasibility with production sensors alone.

Estimator

Simulate x̂[k+1] = A x̂[k] + B u[k] + c, with C = I and D = 0. Fit the four entries of A, two entries of B, two constant offsets c, and two initial-state components. The ten parameters are local to one fixed-speed run. State coordinates remain physical sideslip and yaw rate.

Minimize the sum of squared measurement residuals weighted by the configured state standard deviations (0.01° sideslip and 0.03°/s yaw rate). These are the simulator's declared measurement variances, assumed available for this diagnostic. This assumption is not a claim that real sensor covariances are known exactly. Fit all 2001 consecutive observations and 2000 applied inputs from the 20-second excitation segment.

Numerical centering and scaling do not constrain the operating point: the free affine term is transformed back into physical coordinates. No true equilibrium, clean states, reference matrices, vehicle parameters or validation data are passed to the estimator. No redundant equilibrium/output-offset parameters are added.

Three predetermined initializations: affine OLS A (spectral radius reduced to 0.995 only if larger), 0.9 I, and 0.98 I in whitened coordinates. For each A, initialize B, c and x̂[0] by linear least squares. Use SciPy trust-region least squares with analytic sensitivities, at most 300 function evaluations per start, ftol = xtol = 10⁻⁹ and gtol = 10⁻⁷. Select the converged finite solution with lowest training objective. All attempts, termination reasons, losses and converged physical parameters are saved. Numerical overflow trials receive a large residual barrier; no stability constraint, oracle regularization, or silent OLS fallback is used. Save the final spectral radius, Jacobian rank/condition and elapsed time for diagnosis. Solver convergence alone does not certify a unique or accurate model.

Evaluation and decision

Use the original physical matrix reference and the independent chirp validation maneuver. Primary metrics preserve the prior criteria: relative six-entry matrix error ≤ 10%, normalized one-second rollout RMSE ≤ 0.5, and improvement over persistence. Canonical rollout uses the same known-input validation center for all methods and ignores fitted affine offsets, matching the frozen comparison. A second metric evaluates the complete affine model using its training-derived offset, with no validation offset fit. Both initialize each one-second window from the exact simulator state, as in the original diagnostic; this is not an observer test.

All failed optimizations remain in the accuracy denominator. Numeric percentiles exclude failed fits and report n_valid explicitly. A descriptive profile pass requires ≥95% of cells to pass the original criteria, with all physical and settling checks passing. Report all three profiles, speeds and fleets; do not treat correlated cells as independent fleet replications. The full-affine validation metric is a diagnostic, not a newly tuned acceptance threshold.

Inspect convergence, start-to-start parameter differences, low-speed errors and full-affine predictions before deciding whether the local estimator is ready. No automatic confirmation unlock, changed pilot selection or manuscript update. Even a passing pilot requires a frozen revised protocol and independent confirmation. Changes to local estimator uncertainty and downstream equivalence claims require separate review.

Run on Windows CMD

git pull --ff-only
conda activate federated_lpv
python code/experiments/paper_structured_oe_diagnostic.py preflight
python code/experiments/paper_structured_oe_diagnostic.py smoke
python code/experiments/paper_structured_oe_diagnostic.py run --workers 5

No new dependencies are required beyond the existing environment. BLAS threads are limited inside each fit. The spawned synthetic smoke test saves no scientific results. Jobs resume by validating and skipping complete checkpoints. Each completed seed/profile job is saved atomically; an interrupted unfinished job restarts.

If the original NPZ arrays are missing, recover them with the existing hash-exact reconstruction before run:

python code/experiments/paper_structured_oe_diagnostic.py restore --workers 5

Restoration must match every original array hash. It does not substitute approximately matching data.
