Finish two fits, then consolidate

Numerical closure of the matched peer-speed experiment. Only the 13 m/s SameSpeed conditions in fleets 1301 and 1302 are resumed. No new training data, initialization, baseline, hyperparameter or test condition is introduced.

Frozen scope

ItemAction
StartExact saved round-30 parameters, center, history and communication counter
StopOriginal convergence criteria, with an emergency cap of 100 total rounds (at most 70 additional)
Local solverOriginal per-update budget and tolerances; no initial local OE refits
DataReuse the original nine 13 m/s records per affected fleet, checking their saved hashes
EvaluationOnly six affected targets: 7 speeds × 2 probes × 6 targets = 84 predictions

The cap is a safeguard, not a prescribed execution length. The original criteria remain: stable assignments, relative objective change below 10⁻⁶, maximum log-parameter movement below 10⁻³, and converged client solves. Stop immediately when all pass. A run reaching 100 rounds remains explicitly budget-exhausted. Test performance never determines the stopping round.

The server center update and exact nonlinear local solver are reused from the original implementation. The preserved history is checked against the original checkpoint on resumption. A failed local update stops the affected continuation with its checkpoint preserved; there is no replacement model.

Efficient execution and recovery

Two workers process the two fleets concurrently, with internal numerical thread limits. Save each client update, completed round and evaluation case. Repeating the run command skips completed work and resumes an interrupted round. There is no new checkpoint or computation for fleet 1303.

Use the original machine and Conda environment. Load saved SameSpeed raw records when available; otherwise reconstruct them and require exact numerical-byte hash agreement. The same checks apply to the original test traces. A mismatch stops execution, preserving the inputs. No original trajectory file is rewritten.

Only one finish runner may be active. After a forced termination, remove results\data\paper_federated_relaxation_peers_finish\run.lock only after checking that no finish worker remains active.
