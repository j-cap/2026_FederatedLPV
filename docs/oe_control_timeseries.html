Closed-loop time-series figure: frozen first-draft protocol

Purpose: illustrate tracking through speed and turn-demand changes, steering activity, and the previously reported recipient tradeoff. This is a replay of saved cases, not new identification, tuning, independent validation, or a claim of large absolute tracking gains.

Selection fixed before viewing trajectories

  1. For each of the ten fleets, build six mean yaw-RMSE components: moderate and hard maneuvers, each with Nominal LTI, Global, and Federated. Each mean uses all 30 clients.
  2. Compute the component-wise median and population standard deviation across fleet vectors. Select the smallest Euclidean distance to the median after scaling each component by its standard deviation.
  3. Within that fleet, apply the same rule separately to the ten heavy and ten handling clients, using all six RMSE components. No requirement on Federated improvement is applied.
  4. Numerically constant components are omitted when their spread is at most 64 machine epsilons times max(1, absolute median). Exact distance ties choose the lowest seed or client index.

The resulting selection is fleet 1319, heavy_05 (index 15), and handling_07 (index 27). It is checked against the fixed configuration. Display the hard maneuver; both maneuvers enter selection. Families are intentionally chosen to illustrate the already established tradeoff, so these are outcome-based representative examples, not random or fleet-average trajectories. All candidate distances are saved for review.

All data panels are 3.48 inches wide. The two reference panels are 1.35 inches high; error and steering panels are 1.65 inches high. A separate paper_oe_control_timeseries_legend.pdf strip (7.16 × 0.30 inches) supplies one controller legend for the entire composition. The HTML preview labels the columns “Heavy recipient” and “Handling recipient”; the final LaTeX layout will supply those labels and subcaptions. Fonts use the current manuscript's serif style, 8-point labels and 7-point ticks. PNG previews are 300 dpi. Colors and line styles distinguish the three methods in color and grayscale.

The reference yaw-rate panel uses explicit −40, −20, 0, and 20 deg/s ticks. Both recipients have identical error and steering axes. The error range includes every sample of all six traces, with a small margin; no zoom window, smoothing, or resampling is used. Applied steering is a zero-order-hold step plot. Dotted lines show ±12° amplitude limits, and the full limiting range is visible. The yaw error convention is r − r_ref. Longitudinal speed is prescribed, not tracked by a longitudinal controller.

Replay and provenance

Preflight checks the original numerical runtime, frozen source hashes, stored checkpoint hashes, protocol, and selection. Generation reuses the saved gains/prefilters, plant parameters, and stored maneuver profiles for only two recipients × three methods. Each complete outcome dictionary and every trajectory-array hash must match the saved checkpoint exactly before any figure is exported. There is no tolerance fallback, controller redesign, or modification of historical results. A mismatch stops the script for diagnosis.

The manifest records the rule, all candidate rankings, input and generator hashes, replay checks, runtime, and output hashes. A CSV contains the selected traces in physical units. Its terminal steering cell is empty because no input interval follows the last state. The HTML preview embeds all six SVG panels and the shared legend and case RMSEs and works offline.

Run locally in Windows CMD

conda activate federated_lpv
git pull --ff-only origin main
python paper\prepare_oe_control_timeseries.py --preflight
python paper\prepare_oe_control_timeseries.py --generate
python paper\prepare_oe_control_timeseries.py --check
start "" report\paper_oe_control_timeseries.html

The existing environment supplies all dependencies; the script limits numerical threads internally. No worker flag or full experiment rerun is needed. If the numerical environment differs, use the versions in environment.yml. Existing raw arrays are not required.

For an isolated preview, add --output-dir PATH to generate/check. All files then go to that directory. The default output paths are results/figures/, results/tables/, and report/. PNGs are regenerable and ignored by git. The check verifies the six panel PDFs, shared-legend PDF, CSV, and HTML against the manifest without replaying.
