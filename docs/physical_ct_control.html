Closed-loop comparison of the completed structured CT pilot

The identification pilot is complete. This stage tests whether its improved matrix estimates benefit yaw-rate tracking. The three pilot fleets remain the only cohort; no model estimation or controller tuning occurs.

Fixed comparison

ItemSetting
Vehicles90 existing recipients, seeds 1301–1303
MethodsNominal LTI, Restricted Local, Smooth Local, Global, Federated, PhysicalCTLocal
Cases90 × 6 × 3 = 1620 rollouts
ManeuverExisting 12-s smooth left-right yaw reference; active from 2 to 10 s; peak nominal lateral demand 2.5 m/s²
Test speedsConstant 13, 21 and 29 m/s, unobserved locally by every recipient
SynthesisExisting LQI weights Q=diag(25,50,1000), R=0.15; gains/prefilters at 10,12,…,30 m/s, linearly interpolated. Nominal LTI uses the original saved constant gain/prefilter.
Limits12° steering, 120°/s steering rate, 6° sideslip, integral ±0.6 rad and existing conditional anti-windup
Feedback / initializationNoise-free full-state feedback; state, integral and previous steering initialized at zero
ModelsSaved A/B predictions only; no affine OE offsets, initial states, refitting, clipping or fallback

These are the inherited control limits, not the lower steering-rate limit used during data acquisition. Lateral acceleration is reported but is not an additional feasibility gate in this benchmark. The structured model was identified around prescribed steady cornering and is applied to this varying-yaw maneuver without adaptation.

Windows CMD: run locally

conda activate federated_lpv
git pull --ff-only origin main
set OPENBLAS_NUM_THREADS=1
set OMP_NUM_THREADS=1
set MKL_NUM_THREADS=1
python code\experiments\paper_physical_ct_control.py preflight
python code\experiments\paper_physical_ct_control.py smoke
python code\experiments\paper_physical_ct_control.py run --workers 3

Preflight checks the fixed experiment inputs and all 90 converged identification fits. Smoke runs the nominal synthetic vehicle at three speeds in a spawned worker and checks checkpoint serialization. It writes no scientific result files.

The run delegates to the existing control implementation and saves after each vehicle, preserving all methods and speeds together. Repeating the command resumes. No calibration NPZ files are required. Existing results from the earlier optional control command are reused only after validation. Do not run both commands simultaneously.

python code\experiments\paper_physical_ct_control.py status

After an interrupted process, first stop all remaining workers. Only then remove a stale results/data/paper_physical_ct_oe/pilot_control.lock if it blocks resumption.

The focused report requires all 1620 cases. It presents synthesis/numerical failures and feasibility first, then tracking RMSE, peaks, sideslip, steering effort/rate, actual lateral acceleration and limiter activity. It includes fleet and speed summaries and paired absolute tracking differences.

Aggregation is equal speeds within vehicle, equal vehicles within fleet, then equal fleets. Finite infeasible runs remain in the means. Any unavailable full-duration error makes the corresponding full fleet mean unavailable. There are no survivor-only victories, replacement seeds, retuning or significance claims from three reused fleets.

Decision after the run

Compare PhysicalCTLocal with Federated, Global and Nominal LTI in absolute tracking units and under the same constraints. A small absolute tracking difference is reported as such, even if a relative percentage looks large. Inspect the low-speed identification block and its uncertain friction estimates. Closed-loop gains would strengthen the structured baseline; a lack of gains would reveal limited controller sensitivity rather than erase the identification finding.

The next experiment and manuscript changes are deliberately left for the joint review of these results.
