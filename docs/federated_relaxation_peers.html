Does complementary speed coverage supply useful information?

Frozen development diagnostic: compare converged personalized FL with complementary-speed peers against the same method with the same peers operating at the target's own speed. Preserve all original results. Run no controller study or manuscript update.

Matched intervention

Use the existing three pilot fleets (1301/1302/1303), each with nine vehicles. Every vehicle serves as a target once, with its original 12 s local record at 13, 21 or 29 m/s. Its eight peers are exactly the same physical vehicle realizations in both conditions.

For a target observed at 13 m/s, the complementary fleet contains three records at each of 13/21/29 m/s. In SameSpeed, all nine vehicles are recorded at 13 m/s. Six peer records change speed; two already at 13 m/s and the target record stay identical. The comparison for targets at 21 or 29 m/s follows the same construction.

A uniform-speed fit is shared computationally by the three targets originally observed at that speed. This requires three SameSpeed fits per fleet rather than nine separate target fits. It is algebraically the same cohort and objective for those three targets. No target uses its own counterfactual records from the other speed conditions, and no estimates are shared between conditions.

Data and initialization

Across three fleets, construct 54 new counterfactual training records and reuse 27 originals. Keep the plant, geometry, 0.4/0.7 m true relaxation lengths, 10 ms sampling, 1 ms RK4 substeps, known steering, zero initial state and 0.03 deg/s yaw measurement noise unchanged.

For each new record, simulate the same physical vehicle at the new fixed speed with the original steering. Add that vehicle's exact original training-noise vector. Noise vectors remain independent between vehicles, and intentionally paired across speed conditions. Input duration, frequencies, phases, amplitude and sample count stay fixed. Yaw amplitude and parameter sensitivity naturally change with speed; matching input amplitude does not match output signal-to-noise ratio.

Each new record receives the original three common OE starting guesses (162 new local optimizer starts total). Do not warm-start from the vehicle's estimate at another speed. At its original speed, reuse its original local OE fit exactly. Initialize each fleet center and individual parameters from those condition-local solutions, then use the original alternating algorithm with the original penalty. Friction remains locally unregularized. Ground-truth parameters are used only by simulation and evaluation, never for estimation or server updates.

The original target LocalOE and NominalPrior models are reused as baselines; no additional baseline fits are needed. Complementary fits come from the converged continuation, not the earlier eight-round estimates. All six source checkpoints are locked by hash.

Evaluation and interpretation

Evaluate each target's SameSpeed model on its unchanged seven-speed, two-probe test set. Reuse LocalOE, NominalPrior and converged Complementary metrics on those exact cases. This adds 378 model prediction evaluations and yields 1512 comparison rows across four methods. Test noise is unchanged and separate from training.

Primary question: does Complementary improve target-unseen error beyond both SameSpeed and NominalPrior without unacceptable target-observed degradation? No effect-size threshold or hyperparameter is chosen from test results.

A gain over LocalOE alone is insufficient. If both peer conditions perform similarly, generic regularization or additional peer observations can explain the benefit. If complementary peers help only low-speed targets, describe that conditional result. Three reused pilot populations do not support an independent confirmation claim, and repeated trajectories are not independent fleet replicates.

This intervention tests the effect of changing peer operating speeds, including the resulting excitation/sensitivity and output-noise-ratio changes. It does not separately establish a geometric-coverage mechanism. Shared true relaxation lengths favor transfer. Grouped FL and closed-loop control remain outside this experiment.

Failure handling and efficiency

Run one worker per fleet, at most three workers; numerical thread limits are set internally. Save each training record, local optimizer start, personalized client update, completed round and test case. Rerunning skips saved work, including partial rounds. Use the same original machine/environment; original arrays must match their stored hashes, whether loaded or reconstructed.

A training operating-check failure stops that fleet with its case preserved. A failed local initialization or personalized update marks the affected SameSpeed condition unavailable; there is no fallback model. The remaining conditions still run. Finite budget-exhausted models are evaluated with their status explicit. Full means and paired effects are withheld when any expected model is unavailable. Check convergence before interpreting differences.

The runner writes only its new result prefix. Compressed raw arrays are ignored by git, while checkpoints preserve reconstruction inputs, parameters, metrics and hashes. Restoration checks exact numerical-byte hashes. Logical communication counts reflect each fitted condition, including all local messages, and exclude transport overhead.

Only one peer-experiment runner may be active. After forced termination, delete results\data\paper_federated_relaxation_peers\run.lock only after confirming that no peer-experiment process remains active.
