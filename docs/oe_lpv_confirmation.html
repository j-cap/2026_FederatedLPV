Question

Does grouping locally identified models improve recipient-unobserved-speed model accuracy over Smooth Local and Global on fresh fleets? This stage confirms model identification and sharing, not a closed-loop controller benefit.

Prospective amendment OE-LPV-2 and failure policy

As in the development integration, actuator limiter activity is allowed because actual applied steering is known. Applied state/input bounds and settling remain mandatory. The historical zero-limiter criterion remains failed and is not rewritten. There is no filtering prerequisite and no claim of smooth ordinary driving or real-world data.

All cells are attempted and saved. Invalid local fits or bound/settling failures block that condition for the entire fleet; no cell is discarded on the basis of reference accuracy. Numerical failures are recorded. Unexpected software errors stop execution with existing progress preserved. Failed cells are not automatically retried; any corrective change requires an explicit protocol/version decision. Unstable learned matrices remain visible. No failed fleet may be replaced.

Primary endpoint and decision

Relative Frobenius error of the six A/B entries, averaged over each client's unobserved speeds, then equally over clients. Each fleet is one independent paired unit. The two primary contrasts are Smooth Local minus Federated and Global minus Federated, expressed in percentage points.

Report all ten paired differences, win counts and two Bonferroni-adjusted 97.5% two-sided Student-t intervals, giving simultaneous family confidence of at least 95% under the paired-t assumptions. This is approximate inference based on independent, sufficiently regular fleet differences; n=10 remains limited. The prespecified primary improvement claim requires both lower bounds above zero, all ten valid primary fleets, and all primary same-partition equivalence checks passing. Otherwise report the result as not confirmed under this criterion. Percentage improvements and secondary comparisons are descriptive. Numerical equivalence failure requires investigation, not a favorable claim.

python code\experiments\paper_oe_lpv_confirmation.py preflight
python code\experiments\paper_oe_lpv_confirmation.py smoke
python code\experiments\paper_oe_lpv_confirmation.py run --workers 5

Five processes run at most five fleets at once, with numerical library threads limited to one per worker. Each fleet saves an atomic acquisition checkpoint after every local cell. Running the same command resumes completed cells and skips finished fleets, after verifying hashes. The smoke test uses a nominal technical fixture and synthetic regression data only; it does not sample reserved fleets.

python code\experiments\paper_oe_lpv_confirmation.py status

An exclusive lock prevents two executions writing the same files. After a hard crash, only once all old Python workers have stopped, remove results\data\paper_oe_lpv_confirmation\execution.lock if it remains, then rerun. Stale or corrupt checkpoints cause an error, never silent overwriting.

Reconstruct ignored trajectories

python code\experiments\paper_oe_lpv_confirmation.py restore --workers 5

Restores only missing raw arrays from saved vehicle parameters, acquisition seeds and frozen sources. Every array hash must match its committed acquisition checkpoint. Existing arrays are checked too. Fits and checkpoint files are not altered. A nominal smoke fixture tests delete-and-restore hash equality. Use the pinned environment; numerical platform differences can make bitwise reconstruction fail and must be investigated rather than accepted silently.

Scope and reproducibility

The runner checks nested development provenance, pinned package versions, frozen controller design, configuration and source hashes. It records inputs, learned coefficients, assignments, all candidate scores, raw-array hashes and evaluation references. Family labels and full-envelope references enter only diagnostic/evaluation functions after primary fits. No manuscript changes accompany this freeze. The original development scripts and results remain unchanged.
