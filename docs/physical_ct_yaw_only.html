Isolate identification without measured sideslip

Question and fixed comparison

Does removing the sideslip measurement from the structured continuous-time OE objective materially impair local model identification? Fit one joint model for each of the original 90 pilot vehicles (seeds 1301–1303), using its original 2–3 speeds and 40–60 s of data. Reuse the 90 committed full-state-trained physical CT fits. Keep the tanh plant, vehicle parameters, geometry, acquisition controller, noise, known applied steering, parameterization, bounds, four initial guesses and optimizer tolerances unchanged. No new sharing method or coverage restriction.

The estimator receives only a one-dimensional measured-yaw array, applied steering and fixed speed for each segment. No measured/true sideslip, true vehicle parameters, family labels or holdout data cross the fitting boundary. All starts are saved and selection uses only converged yaw training losses. The numerical sideslip coordinate scale is fixed at the old noise scale; it is not a sideslip observation.

This is an identification sensing ablation, not a sensor-free operating workflow. Existing recordings were acquired under a controller using noisy full-state measurements. The optional later LQI diagnostic uses noise-free true state feedback. An observer and new acquisition are deliberately deferred.

Hidden state and nuisance quantities

At each fixed speed simulate x[k+1] = A(theta)x[k] + B(theta)u[k] + c, yhat[k] = [0,1]x[k]. The old free initial state and two-component offset contain one exact yaw-only redundancy. For d = [beta_initial,0], the change x' = x − d leaves yaw unchanged and changes the offset to c' = c + (A − I)d. Fixing the hidden initial sideslip to zero therefore removes only this redundancy; it is not an assumption about the true vehicle state.

Variable projection solves for the two offsets and initial yaw. An SVD with relative cutoff 10^-12 handles any additional rank deficiency. The exact projected-residual Jacobian is used on constant-rank regions. Save nuisance ranks, all four physical parameter sensitivities, per-speed sensitivities, near-bound flags and all optimization attempts. A converged fit is not an identifiability certificate. The hidden affine sideslip offset is not uniquely recovered.

1. Run identification (Windows CMD)

git pull --ff-only origin main
conda activate federated_lpv
python code\experiments\paper_physical_ct_yaw_only.py preflight
python code\experiments\paper_physical_ct_yaw_only.py smoke
python code\experiments\paper_physical_ct_yaw_only.py run --workers 3 --restore-missing

The runner sets BLAS/OpenMP/MKL thread limits internally. Three processes fit one fleet each. It checkpoints every vehicle using unique temporary files and bounded retry for Windows file locks. Rerun the same command to resume. Existing baseline checkpoints and scientific results are never replaced.

Original ignored trajectory arrays are required. Missing arrays can be regenerated with the original acquisition code, seeds and controller. Their committed array and input hashes must match exactly; no mismatch is accepted. Run reconstruction on the original machine/environment. The flag above restores only missing arrays. Alternatively restore them first with:

python code\experiments\paper_physical_ct_yaw_only.py restore --workers 3

A preflight count of missing arrays is informational. If a hash mismatch occurs, keep the original saved arrays or reconstruct on their original platform; do not weaken the hash check. File-lock retries preserve the previous checkpoint and retain a complete pending file on persistent failure. A stale execution lock should only be removed after confirming no workers remain.

Checks before handoff

Regression tests cover analytical projection derivatives, equivalence to the redundant four-nuisance yaw response, noiseless joint recovery, single-speed ambiguity, rank-deficient nuisance projection, rejection of sideslip inputs, invariance to changes in sideslip channels, validation-suffix independence, and failed-fit accounting/report generation. The smoke command uses a spawned worker and synthetic data, checks parameter recovery and UTF-8 checkpoint round-trip, and writes no scientific results.
