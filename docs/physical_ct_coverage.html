Does narrower local coverage impair a useful physical model?

A diagnostic on the same 90 pilot vehicles, with the same nonlinear tanh plant and four-parameter continuous-time output-error estimator. No shared models, new vehicle populations, new acquisition or controller retuning.

Frozen comparisons

FullOriginal 2–3 speeds, 20 s each (40–60 s)Reuse the existing structured local CT fit and closed-loop result.
SingleEach original speed separately, 20 sExpose the stiffness/friction ambiguity. Keep every speed variant, without picking a favorable one.

Multi-speed 20 sOriginal speed set, 20 s totalCompare speed diversity with a single-speed trajectory at a matched total number of transitions.

Scope: seeds 1301–1303, every vehicle, every eligible subset. There are 588 condition records: 90 full, 249 single-speed, 159 adjacent-pair and 90 multi-speed 20 s. This requires 477 new fits; 111 conditions reuse original full fits. Each fit keeps the original four starts, parameter bounds, free offsets and free initial states.

For the 20-second multi-speed condition, distribute exactly 2000 transitions in ascending speed order: 667/667/666 for three speeds, or 1000/1000 for two. Take a central contiguous window from each original 2000-transition trajectory, including its terminal measurement. Never concatenate states across speeds or repeat measurements.

Equal total duration does not imply identical excitation or equal information. Cropping changes the waveform portions, and multiple trajectories have more nuisance offsets/initial states. This is an efficient existing-data diagnostic. Fixed curvature also means that speed diversity changes lateral demand κv².

What is measured

The primary prediction metrics are relative matrix error for [A,B] and identity-free error for [A−I,B], evaluated on the original unobserved even-speed grid. That evaluation set is held fixed across all variants of a vehicle. All-grid and actually-unobserved errors are also saved.

Record convergence, bounds, log-parameter residual Jacobian rank/conditioning, all optimizer starts, selected parameters, training loss, exact selected-data hashes and the fitted model at every grid speed. For one speed, sample a bounded equivalent parameter family: varying μ and rescaling p₁,p₂ can preserve the observed-speed dynamics exactly. Report how those equivalent models differ elsewhere. This is an ambiguity diagnostic, not a confidence interval or a truth-based parameter-selection rule. A converged single-speed fit is not evidence that all four parameters are identifiable.

The optional separate control stage evaluates every fitted condition on the existing 13/21/29 m/s, 12-second smooth left-right maneuver. Same gain grid, Q/R, interpolation, limits, zero initialization and noise-free state feedback. It requires 1431 new rollouts; 333 case records reuse full-coverage controls, for 1764 total recorded cases. No repair, fallback or tuning is performed. Fit/synthesis/rollout failures remain explicit.

Average variants within each vehicle first, then vehicles within fleets, then the three fleets equally. Also save every variant, worst-variant identification errors, and summaries by original coverage block. Full means are unavailable if any contributing fit or full-duration rollout fails. Finite constraint-violating trajectories remain in tracking means. No p-values or independent-confirmation claims.

1. Pull, check, and run identification

git pull --ff-only origin main
conda activate federated_lpv
python code\experiments\paper_physical_ct_coverage.py preflight
python code\experiments\paper_physical_ct_coverage.py smoke
python code\experiments\paper_physical_ct_coverage.py run --workers 3 --restore-missing

The runner limits numerical-library threads internally. No repeated OPENBLAS/OMP/MKL commands are needed. Each fleet runs in a separate Windows-compatible spawned worker; every completed condition is saved atomically, so rerunning the command resumes.

The original ignored acquisition arrays are needed. Existing arrays are checked against the original committed hashes. --restore-missing reconstructs missing arrays and checks those hashes before fitting. To restore them separately:

python code\experiments\paper_physical_ct_coverage.py restore --workers 3

Use the original machine/numerical environment when restoring. If reconstruction differs from the committed hashes, the runner stops; use the original arrays or restore in the original environment. It never relaxes the hashes or replaces the frozen results.

Decision after this pilot

First assess whether narrower coverage meaningfully worsens common unseen predictions or tracking. Poor friction recovery or rank deficiency alone is insufficient. Then examine whether keeping several speeds within the same 20-second budget helps. The single-speed equivalence family shows which conclusions depend on unresolved parameter choices.

If a relevant limitation appears, the next experiment can compare structured local, pooled and grouped learning with exactly the same restricted per-vehicle data. Existing Federated results use the original coverage and are not a matched sharing comparator here. If strong local predictions and control persist, preserve that negative result rather than automatically tightening the conditions further.
